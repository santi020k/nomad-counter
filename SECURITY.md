# Security policy

Security updates are provided for the current `main` branch.

Report vulnerabilities through [GitHub private vulnerability
reporting](https://github.com/santi020k/nomad-counter/security/advisories/new).
Do not open a public issue or include travel history, email codes, session
cookies, or Cloudflare credentials in a report.

Include the affected component, reproduction steps, impact, and any suggested
mitigation. Reports will be acknowledged as soon as practical.
